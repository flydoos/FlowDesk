# 🌈 FlowDesk（流光动态桌面）

你是不是也受够了千篇一律的静态壁纸？每天对着同一张图片，早就看腻了？

**FlowDesk（流光动态桌面）** 能让你的桌面彻底"活"过来！它是一款免费的 Windows 动态桌面壁纸软件，可以把 **高清视频、炫酷动画、鼠标互动特效** 直接变成你的桌面背景。流光桌面——唤醒你，静止的桌面！

✨ 鼠标轻轻一划，绚烂的流光跟着你的指尖起舞；

🐼 周末切到熊猫懒懒，看着圆滚滚的国宝在竹林里打滚……

**小巧绿色便捷，不用装臃肿的壁纸平台，解压即用，零广告零弹窗。** 从可爱萌宠到炫酷特效，从国风悟空到 3D 办公室，数十款精选主题免费使用。白天清新、夜晚酷炫，还能根据时间自动切换，你的桌面从此与众不同。

**支持 Windows 10 / 11 全平台，多显示器也能完美适配。** 打游戏、看视频时自动暂停，不占一丝多余资源——好看，但绝不添乱。

## ✨ 功能特色

### 🎬 视频壁纸，丝滑播放
支持 MP4、WebM 等主流视频格式，多个视频自动轮播，切换时采用双缓冲无缝过渡，没有黑屏、没有卡顿，画面永远在线。

### 🖱️ 鼠标互动，桌面能"玩"
部分主题支持鼠标跟踪——你的鼠标走到哪，光影特效就跟到哪；划一划就能拖出彩色流光；点一点粒子就四散飞舞。这不是壁纸，这是你的桌面游乐场。

### 🌗 自动昼夜切换
设定好时间，白天自动用清新明亮的主题，晚上自动切到酷炫沉浸的主题。不用手动操心，你的桌面比你还懂生活节奏。

### 🖥️ 多显示器完美支持
无论你是单屏党还是多屏党，支持复制、单屏、跨屏三种模式，每块屏幕都能单独设置，绝不厚此薄彼。

### 📚 内置主题库，一键换装
几十款精选主题分类展示，带预览图，看中哪个点一下就换上。从萌宠视频到粒子动画，从 3D 场景到节日特效，想换就换，永不无聊。

### 🎮 打游戏自动暂停
检测到全屏游戏或全屏播放视频，壁纸自动暂停释放资源，CPU、GPU 零负担。锁屏、远程桌面时也会自动暂停，省电又省心。

### 🔊 声音独立控制
壁纸音量单独调节，还能一键静音。不会和你的音乐、游戏、视频抢声音。

### 🚀 开机自启，即开即享
设置开机启动后，每次开机桌面就是动态的，不用额外操作，好心情从开机那一刻开始。

### 🌐 中英文界面
支持中文和英文两种语言，切换无障碍。

## 🔨 使用方法

1. 从上方下载地址下载最新版压缩包；
2. 解压到任意目录（建议放在非系统盘，如 `D:\FlowDesk`）；
3. 双击运行 `FlowDesk.exe`；
4. 启动后，系统托盘（右下角）会出现 FlowDesk 图标；
5. **双击托盘图标** 打开主题管理界面，选择喜欢的主题即可；
6. 在「设置」中可配置开机自启、显示模式等选项。

## ❓ 常见问题

**1、为什么我打开软件后没有反应？**

请确保系统已安装 .NET 8.0 Desktop Runtime 和 WebView2 Runtime。通常首次运行时程序会自动安装 WebView2，如果网络不佳可能导致安装失败，可手动下载安装。

**2、如何添加额外的主题？**

将主题文件夹放入程序目录下的 `Themes/Light`（白天主题）或 `Themes/Night`（夜晚主题）文件夹中，重新打开主题管理界面即可看到新主题。

**3、打游戏时壁纸会占用资源吗？**

不会。FlowDesk 会自动检测全屏游戏或全屏视频播放，壁纸会自动暂停释放资源，对游戏性能零影响。

**4、支持多台显示器吗？**

支持！FlowDesk 提供复制、单屏、跨屏三种模式，每块屏幕都能单独设置不同的主题。
